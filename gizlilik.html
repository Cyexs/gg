Gizlilik Politikası / Privacy Policy

Yürürlük / Effective: 2 Kasım 2026 / 2 November 2026

Türkçe

Bu politika, Genç Gözüyle Paylaşım masaüstü aracının ("araç") hangi bilgileri nasıl kullandığını açıklar. Araç yalnız sahibinin bilgisayarında çalışır ve yalnız sahibinin kendi YouTube kanalına ve TikTok hesabına içerik gönderir.

Erişilen bilgiler

  • Yetki anahtarları: Google ve TikTok'un OAuth akışıyla verdiği erişim ve yenileme anahtarları. Yalnız sahibin bilgisayarındaki yerel bir dosyada saklanır; hiçbir sunucuya, üçüncü kişiye ya da araç geliştiricisine gönderilmez.
  • Yüklenen içerik: sahibin bilgisayarındaki video dosyası ile başlık, açıklama ve etiket metni. Bunlar yalnız ilgili platformun resmî API'sine (YouTube Data API, TikTok Content Posting API) gönderilir.
  • Yükleme sonuçları: video kimliği, bağlantı, işlem durumu ve hata iletileri; yalnız yerel kayıt dosyasında tutulur.

Araç başka hiçbir kişisel veri toplamaz; YouTube veya TikTok hesabından izleyici, yorum, mesaj, takipçi ya da istatistik verisi okumaz. Veri satılmaz, paylaşılmaz, reklam veya profilleme için kullanılmaz. Çerez ya da analiz aracı kullanılmaz.

YouTube API Hizmetleri

Araç YouTube API Hizmetlerini kullanır. Aracı kullanan kişi YouTube Hizmet Şartları'na bağlı olmayı kabul eder. Google'ın verileri nasıl işlediği Google Gizlilik Politikası'nda anlatılır.

Saklama ve silme

Anahtarlar, sahip izni geri alana ya da yerel dosyadan silene kadar saklanır. İzni istediğin an geri alabilirsin:

  • Google: myaccount.google.com/permissions (ayrıca güvenlik ayarları) → Genç Gözüyle Paylaşım → Erişimi kaldır.
  • TikTok: Ayarlar ve gizlilik → Güvenlik ve izinler → Uygulamalar → Genç Gözüyle Paylaşım → Kaldır.

İzin geri alındığında araç o platforma erişemez. Yerel anahtar ve kayıt dosyaları sahibin bilgisayarından silinerek tamamen kaldırılır.

English

This policy explains what information the Genç Gözüyle Paylaşım desktop tool ("the tool") uses and how. The tool runs only on its owner's computer and only sends content to the owner's own YouTube channel and TikTok account.

Information accessed

  • Authorization tokens: access and refresh tokens issued by Google and TikTok through OAuth. They are stored only in a local file on the owner's computer and are never sent to any server, third party or the tool's developer.
  • Uploaded content: the video file on the owner's computer and its title, description and tags. These are sent only to the official API of the platform concerned (YouTube Data API, TikTok Content Posting API).
  • Upload results: video ID, link, processing status and error messages, kept only in a local log file.

The tool collects no other personal data and does not read viewers, comments, messages, followers or analytics from YouTube or TikTok. No data is sold, shared, or used for advertising or profiling. No cookies or analytics are used.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. How Google processes data is described in the Google Privacy Policy.

Retention and deletion

Tokens are kept until the owner revokes access or deletes them from the local file. You can revoke access at any time:

  • Google: myaccount.google.com/permissions (also security settings) → Genç Gözüyle Paylaşım → Remove access.
  • TikTok: Settings and privacy → Security and permissions → Apps → Genç Gözüyle Paylaşım → Remove.

Once access is revoked the tool can no longer reach that platform. Local token and log files are removed completely by deleting them from the owner's computer.
